# ============================================================================
# CAMPAIGN VOCABULARY
# ============================================================================
# Names Whisper has no chance of guessing. These get fed to the transcriber
# as a bias hint, so it writes "Vesper Kane" instead of "Vesper cane" or
# "Whisper Cain". This is the single biggest accuracy lever you have.
#
# FORMAT
#   One term per line. Anything after a # is a comment. Blank lines ignored.
#   Commas on a line also work, so you can paste in a list.
#
# THE BUDGET -- READ THIS
#   Whisper's prompt is capped at ~223 tokens, which after the built-in 5e
#   glossary leaves room for roughly 30-40 short campaign terms. That is a
#   hard ceiling in Whisper itself, not a setting we can raise.
#
#   Terms nearest the TOP of this file are kept first. If you overflow, the
#   bottom entries are dropped and you'll get a warning in bot.log saying
#   exactly which ones. So: most-mangled, most-frequent names at the top.
#
# WHAT TO ADD
#   Proper nouns a general speech model has never seen: PCs, recurring NPCs,
#   place names, factions, homebrew items and spells.
#
# WHAT NOT TO ADD
#   - Ordinary English words ("the tavern", "the sword") -- wasted budget.
#   - Standard 5e terms (Fireball, Paladin, Counterspell, owlbear, d20) --
#     already covered by the built-in glossary in dnd_vocabulary.py.
#   - One-off NPCs who appeared once and died. Keep this list live: prune
#     names that stop coming up.
#
# Takes effect on the next bot restart.
# ============================================================================
