# 🪶 The bot picks up a quill

## ✨ New
- **The bot writes its own release notes:** whenever it gets an update, it reads the changes and posts a write-up here in #dndbot-release-notes, covering what's new, how to use it, and what got fixed. You're reading the very first one. It's like a wizard copying spells into their own spellbook, except it also explains them to the party.
- The bot's owner can type `!releasenotes` to post the notes straight away instead of waiting for the bot to restart.
- *Nerd corner:* only finished changes get announced, so half-done experiments never show up here. If something goes wrong while it's writing, it marks nothing as done and simply tries again next time it starts up. It also reads its earlier posts first, so it keeps the same voice and doesn't re-announce old features as new.

## 🔧 Improved
- **Quotes come with context:** every quote in #quotes now gets a short italic setup line above it, so it still makes sense weeks later when nobody remembers what was going on:
> *Joe mentions he leaves for work at 6:45.*
> > Everyone likes a morning quickie.
> — **Thia (Goose)**, 24 Oct 2026
- Quotes picked by a recap get their setup line at the same moment they're chosen. Quotes you add with ⭐ or `!quote` post instantly as before. A few seconds later the bot reads the conversation around the quote and edits the setup line in. If that step fails, the quote just stays as it was. Nothing gets lost.
- *Nerd corner:* the bot marks the exact quoted line in the transcript, so it describes the right moment and not something said nearby. It's told to set the scene like a stage direction without explaining the joke. It uses character names for in-game moments and real names for out-of-character ones, and never mixes both for the same person.
