# GPU acceleration for faster-whisper on Windows: ships cuBLAS/cuDNN as DLLs
# inside the venv instead of requiring a system CUDA Toolkit install. See
# transcription/transcriber.py's _register_cuda_dll_dirs(). nvjitlink is a
# genuine runtime dependency of cuBLAS 12.x that pip does NOT pull in
# automatically -- without it, cuBLAS itself fails to load with a
# misleading "Library cublas64_12.dll is not found or cannot be loaded"
# (Windows reports an unresolved *dependency* of a DLL the same way it
# reports the DLL itself being missing). cuda_nvrtc IS auto-installed as a
# transitive dependency of cublas today, but is pinned explicitly here since
# our code imports it by name.
